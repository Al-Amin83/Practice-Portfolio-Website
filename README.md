# Practice Portfolio Website

A modern and responsive personal portfolio website built using **HTML5** and **CSS3**. This project showcases personal information, technical skills, featured projects, and contact details in a clean and professional layout. It is designed as a practice project for improving frontend web development skills and creating a personal online presence.

## 🌟 Features

* Responsive and modern design
* Clean navigation bar with icons
* Professional hero section
* Skills showcase with technology cards
* Project portfolio section
* Contact form
* Social media links
* Custom styling with CSS
* Font Awesome icons integration
* Google Fonts support

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts (Poppins)
